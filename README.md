# StroyService
🏗️ Веб-сайт строительной компании «СтройСервис»
Клиент-серверное веб-приложение с онлайн-конфигуратором домов, калькулятором ремонта и системой обработки заявок. Проект выполняется в рамках учебной программы с имитацией реального взаимодействия заказчика и исполнителя.

📋 О проекте
Бизнес-цель: Создать удобный цифровой канал взаимодействия с потенциальными клиентами, сократить трудозатраты менеджеров на первичный подбор услуг и предварительный расчёт.
Цель проекта: Разработать функциональный прототип сайта с каталогом проектов, пошаговым конфигуратором, калькулятором ремонта, генерацией PDF-смет и административной панелью.
Срок проекта: 21.09.2026 – 10.10.2026 (21 день)
Методология: Гибридная (Предиктивное планирование верхнего уровня + Agile/Scrum на уровне разработки)
Текущий статус: Итерация 0 (Анализ и проектирование)
